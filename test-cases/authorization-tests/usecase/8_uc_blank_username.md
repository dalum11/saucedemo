# ID 8 - поле Username заполнено пробелами
## Описание
Проверка, что система не позволяет выполнить вход, если поле Username ссодержит только пробелы,
и отображает сообщение об ошибке валидации
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются
4. Кнопка Login неактивна

### Тестовые данные
| Название параметра | Значение                        |
|--------------------|---------------------------------|
| Логин              | * Один пробел<br/>* Три пробела |
| Пароль             | secret_sauce                    |

### Шаги
| Номер шага | Название шага                           | Ожидаемый результат                                                                                                                    |
|------------|-----------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------|
| 1          | В поле Username ввести пробел           | * Поле заполнено пробелом<br/>* Кнопка Login неактивна                                                                                 |
| 2          | В поле Password ввести Пароль           | * Поле заполнено маскированными символами<br/>* Кнопка Login доступна для нажатия                                                      |
| 3          | Нажать кнопку Login                     | * Пользователь остаётся на форме авторизации<br/>* Под формой появляется красный саджест с текстом Epic sadface: Username is required  |                                                                                                                                   |
| 4          | Заполнить поле Username тремя пробелами | * Поле заполнено тремя пробелами<br/>* Кнопка Login доступна для нажатия                                                               |
| 5          | Нажать кнопку Login                     | * Пользователь остаётся на форме авторизации<br/>* Под формой появляется красный саджест с текстом Epic sadface: Username is required  |

## Связанный автотест
ErrorLoginTest.loginWithEmptyUsername_ShouldShowUsernameRequiredError()
