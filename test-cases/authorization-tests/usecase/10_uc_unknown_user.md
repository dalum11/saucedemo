# ID 10 - Авторизация пользователя, которого нет в системе
## Описание
Проверка, что система не позволяет выполнить вход для пользователя, данных которого нет в системе, и 
получение ошибки авторизации
### Статус
Успешен
### Приоритет
Критический
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются
4. Кнопка Login неактивна

### Тестовые данные
| Название параметра | Значение         |
|--------------------|------------------|
| Логин              | unknown_user     |
| Пароль             | unknown_password |

### Шаги
| Номер шага | Название шага                                        | Ожидаемый результат                                                                                                                                                           |
|------------|------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1          | В поле Username Логин                                | * Поле заполнено данным из Логин<br/>* Кнопка Login неактивна                                                                                                                 |
| 2          | В поле Password ввести Пароль                        | * Поле заполнено маскированными символами<br/>* Кнопка Login доступна для нажатия                                                                                             |
| 3          | Нажать кнопку Login                                  | * Пользователь остаётся на форме авторизации<br/>* Под формой появляется красный саджест с текстом Epic sadface: Username and password do not match any user in this service  |                                                                                                                                   |

## Связанный автотест
ErrorLoginTest.loginWithWrongPassword_ShouldFailAuth()
