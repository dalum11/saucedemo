# ID 9 - поле Password заполнено пробелами
## Описание
Проверка, что система не позволяет выполнить вход, если поле Username ссодержит только пробелы,
и отображает сообщение об ошибке валидации
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются
4. Кнопка Login неактивна

### Тестовые данные
| Название параметра | Значение                        |
|--------------------|---------------------------------|
| Логин              | standard_user                   |
| Пароль             | * Один пробел<br/>* Три пробела |

### Шаги
| Номер шага | Название шага                           | Ожидаемый результат                                                                                                                   |
|------------|-----------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------|
| 1          | В поле Username Логин                   | * Поле заполнено данными  из Логин<br/>* Кнопка Login неактивна                                                                       |
| 2          | В поле Password ввести один пробел      | * Поле заполнено маскированным пробелом<br/>* Кнопка Login доступна для нажатия                                                       |
| 3          | Нажать кнопку Login                     | * Пользователь остаётся на форме авторизации<br/>* Под формой появляется красный саджест с текстом Epic sadface: Password is required |                                                                                                                                   |
| 4          | Заполнить поле Password тремя пробелами | * Поле заполнено тремя маскированными пробелами<br/>* Кнопка Login доступна для нажатия                                               |
| 5          | Нажать кнопку Login                     | * Пользователь остаётся на форме авторизации<br/>* Под формой появляется красный саджест с текстом Epic sadface: Password is required |

## Связанный автотест
ErrorLoginTest.loginWithEmptyPassword_ShouldShowPasswordRequiredError()
