# ID 32 - Успешный разлогин после авторизации
## Описание
Проверка успешного разлогина пользователя после авторизации на сайте
### Статус
Успешен
### Приоритет
Критичный
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются

### Тестовые данные
| Название параметра | Значение      |
|--------------------|---------------|
| Логин              | standard_user |
| Пароль             | secret_sauce  |

### Шаги
| Номер шага | Название шага                 | Ожидаемый результат                                                                                                                                                                                                       |
|------------|-------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1          | В поле Username ввести Логин  | * Поле заполнено<br/>* Введённый текст не маскируется                                                                                                                                                                     |
| 2          | В поле Password ввести Пароль | * Поле заполнено маскированными символами<br/>* Кнопка Login доступна для нажатия                                                                                                                                         |
| 3          | Нажать на кнопку Login        | * Редирект на /inventory.html<br/>* В URL отсутствует параметр /error<br/>* На странице отображается список товаров<br/>* В правом верхнем углу видна иконка Корзина<br/>* В шапке страницы отображается логотип SwagLabs |
| 4          | Нажать на кнопку Меню         | * Появилось меню сайта<br/>* Отображаются элементы All Items, About, Logout, Reset App State                                                                                                                              |
| 5          | Нажать на кнопку Logout       | * Редирект на URL<br/>* В URL отсутствует параметр /error<br/>* Отображается страница авторизации                                                                                                                         |
