# ID 7 - Пустое поле Password
## Описание
Проверка, что нельзя авторизоваться с пустым паролем и получение ошибки
### Статус
Успешен
### Приоритет
Критичный
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются

### Тестовые данные
| Название параметра | Значение      |
|--------------------|---------------|
| Логин              | standard_user |

### Шаги
| Номер шага | Название шага                      | Ожидаемый результат                                                                                                                   |
|------------|------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------|
| 1          | В поле Username ввести Логин       | * Поле заполнено введённым значением<br/>* Кнопка Login недоступна для нажатия                                                        |
| 2          | Попробовать нажать на кнопку Login | * Пользователь остаётся на форме авторизации<br/>* Под формой появляется красный саджест с текстом Epic sadface: Password is required |
