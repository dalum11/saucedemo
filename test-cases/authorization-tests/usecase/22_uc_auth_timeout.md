# ID 22 - Проверка получения браузерной ошибки при превышении таймаута авторизации
## Описание
Проверка, что при падении запроса авторизации (таймаут - 10 секунд) отображается браузерная ошибка, а не
пользовательская

### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Медленный интернет (в консоли разработчика на вкладке Network установлены Throttling: Slow 3G или Offline)
2. Сайт saucedemo не посещался ранее в этом браузере
3. Браузер открыт в режиме Инкогнито (кэш и cookie очищены)
4. Поля ввода должны быть пустыми

### Тестовые данные
| Название параметра | Значение                   |
|--------------------|----------------------------|
| URL                | https://www.saucedemo.com/ |
| Логин              | standard_user              |
| Пароль             | secret_sauce               |


### Шаги
| Номер шага | Название шага                     | Ожидаемый результат                                                                                              |
|------------|-----------------------------------|------------------------------------------------------------------------------------------------------------------|
| 1          | Перейти на сайт saucedemo по URL  | * Открывается страница авторизации<br/>* Поля Username и Password не заполнены<br/>* Кнопка Login неактивна      |
| 2          | Ввести в поле Username Логин      | * Поле заполнено значением из Логин<br/>* Введённый текст не маскируется                                         |
| 3          | В поле Password ввести Пароль     | * Поле заполнено маскированными символами<br/>* Кнопка Login доступна для нажатия                                |
| 4          | Нажать на кнопку Login            | * Появляется лоудер<br/>* По истечению таймаута (более 10 секунд) запроса появляется стандартная ошибка браузера |
