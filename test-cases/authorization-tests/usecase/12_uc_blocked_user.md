# ID 12 - Попытка авторизации заблокированного пользователя
## Описание
Проверка, что заблокированный пользователь не сможет войти в систему и получит соответствующую ошибку
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются
4. Кнопка Login неактивна

### Тестовые данные
| Название параметра | Значение         |
|--------------------|------------------|
| Логин              | locked_out_user  |
| Пароль             | secret_sauce     |

### Шаги
| Номер шага | Название шага                    | Ожидаемый результат                                                                                                                                    |
|------------|----------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1          | В поле Username ввести Логин     | * Поле заполнено значением из Логин<br/>* Введённый текст не маскируется                                                                               |
| 2          | В поле Password ввести Пароль    | * Поле заполнено маскированными символами<br/>* Кнопка Login доступна для нажатия                                                                      |
| 3          | Нажать на кнопку Login           | * Пользователь остаётся на форме авторизации<br/>* Под формой появляется красный саджест с текстом Epic sadface: Sorry, this user has been locked out. |                                                                                                                                   |
| 4          | Закрыть браузер и открыть заново | Страница авторизации загружена                                                                                                                         |
| 5          | Повторить шаги 1-3               | Статус блокировки сохраняется                                                                                                                          |

## Связанный автотест
ErrorLoginTest.loginByBlockedUser_ShouldFailAuth()
