# ID 13 - Сброс данных формы после обновления страницы
## Описание
Проверка, что данные не сохраняются после обновления страницы авторизации, если они не сохранены в браузере
### Статус
Успешен
### Приоритет
Средний
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются
4. Кнопка Login неактивна

### Тестовые данные
| Название параметра | Значение      |
|--------------------|---------------|
| Логин              | standard_user |
| Пароль             | secret_sauce  |

### Шаги
| Номер шага | Название шага                                      | Ожидаемый результат                                                                                   |
|------------|----------------------------------------------------|-------------------------------------------------------------------------------------------------------|
| 1          | В поле Username ввести Логин                       | * Поле заполнено значением из Логин<br/>* Введённый текст не маскируется<br/>* Кнопка Login неактивна |
| 2          | В поле Password ввести Пароль                      | * Поле заполнено маскированными символами<br/>* Кнопка Login доступна для нажатия                     |
| 3          | Обновить страницу (клавиша F5 или кнопка браузера) | * Страница перезагружена<br/>* URL остался https://www.saucedemo.com/                                 |                                                                                                                                   |
| 4          | Проверить состояние формы после обновления         | * Поле Username пустое<br/>* Поле Password пустое<br/>* Кнопка Login неактивна                        |

## Связанный автотест
ErrorLoginTest.loginFieldsStateAfterRefresh_ShouldDisplayEmptyFields()
