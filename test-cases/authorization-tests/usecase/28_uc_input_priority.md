# ID 28 - Проверка приоритета ручного ввода
## Описание
Проверка, что ручной ввод данных пользователя приоритетнее, чем автозаполнение полей авторизации
сохранёнными данными
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Данные пользователя (логин и пароль) сохранены в браузере
2. Ранее уже был выполнен успешный вход с указанными тестовыми данными - Логин (авто) и Пароль (авто)
3. Cookie и кэш не очищены
4. Браузер работает в обычном режиме (НЕ Инкогнито)

### Тестовые данные
| Название параметра | Значение                   |
|--------------------|----------------------------|
| URL                | https://www.saucedemo.com/ |
| Логин (авто)       | standard_user              |
| Пароль (авто)      | secret_sauce               |
| Логин (ручной)     | standard_user              |
| Пароль (ручной)    | secret_sauce               |
