# ID 25 - Успешная первая авторизация в Google Chrome
## Описание
Проверка, что функционал авторизации корректно работает в Google Chrome
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Google Chrome открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются

### Тестовые данные
| Название параметра | Значение      |
|--------------------|---------------|
| Логин              | standard_user |
| Пароль             | secret_sauce  |

### Шаги
| Номер шага | Название шага                 | Ожидаемый результат                                                                                                                                                                                                                                                                                                                                                        |
|------------|-------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1          | В поле Username ввести Логин  | * Поле заполнено<br/>* Введённый текст не маскируется                                                                                                                                                                                                                                                                                                                      |
| 2          | В поле Password ввести Пароль | * Поле заполнено маскированными символами<br/>* Кнопка Login доступна для нажатия                                                                                                                                                                                                                                                                                          |
| 3          | Нажать на кнопку Login        | * Редирект на /inventory.html<br/>* В URL отсутствует параметр /error<br/>* На странице отображается список товаров<br/>* В правом верхнем углу видна иконка Корзина<br/>* В шапке страницы отображается логотип SwagLabs<br/>* Все элементы отображаются без наложений, обрезаний<br/>* Шрифты соответствуют дизайну<br/>* Страница адаптируется под размер окна браузера |

## Связанный автотест
CrossBrowserTest.checkGoogleChromeSuccessAuth()
