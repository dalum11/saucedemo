# ID 33 - Пустые поля Username и Password
## Описание
Проверка, что нельзя авторизоваться с пустыми логином и паролем и получение ошибки
### Статус
Успешен
### Приоритет
Критичный
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются

### Тестовые данные
Нет
