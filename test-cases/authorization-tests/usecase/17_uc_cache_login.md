# ID 17 - Проверка авторизации при потере соединения, если пользователь уже посещал сайт
## Описание
Проверка, что при повторном посещении сайта и потере соединения отображается страница авторизации,
возможен вход в систему
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Сеть потеряна или отключена
2. Сайт saucedemo посещался ранее в этом браузере
3. Браузер открыт в обычном режиме
4. Поля ввода должны быть пустыми

### Тестовые данные
| Название параметра | Значение                   |
|--------------------|----------------------------|
| URL                | https://www.saucedemo.com/ |
| Логин              | standard_user              |
| Пароль             | secret_sauce               |


### Шаги
| Номер шага | Название шага                                       | Ожидаемый результат                                                                                                                                                                                                        |
|------------|-----------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1          | Перейти на сайт saucedemo по URL с потерянной сетью | * Открывается страница авторизации<br/>* Поля Username и Password не заполнены<br/>* Кнопка Login неактивна                                                                                                                |
| 2          | Ввести в поле Username Логин                        | * Поле заполнено значением из Логин<br/>* Введённый текст не маскируется                                                                                                                                                   |
| 3          | В поле Password ввести Пароль                       | * Поле заполнено маскированными символами<br/>* Кнопка Login доступна для нажатия                                                                                                                                          |
| 4          | Нажать на кнопку Login                              | * Редирект на /inventory.html<br/>* В URL отсутствует параметр /error<br/>* На странице отображается список товаров<br/>* В правом верхнем углу видна иконка Корзина<br/>* В шапке страницы отображается логотип SwagLabs  |

## Связанный автотест
SuccessLoginTest.authWithoutConnection_FirstLoginWithCache_ShouldLoginCorrectly()
