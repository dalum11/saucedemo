# ID 27 - Проверка автозаполнения сохранёнными данными
## Описание
Проверка успешной авторизации пользователя с сохранёнными в браузере данными
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Данные пользователя (логин и пароль) сохранены в браузере
2. Ранее уже был выполнен успешный вход с указанными тестовыми данными
3. Cookie и кэш не очищены
4. Браузер работает в обычном режиме (НЕ Инкогнито)

### Тестовые данные
| Название параметра | Значение                    |
|--------------------|-----------------------------|
| URL                | https://www.saucedemo.com/  |
| Логин              | standard_user               |
| Пароль             | secret_sauce                |

### Шаги
| Номер шага | Название шага                          | Ожидаемый результат                                                                                                                                                                                                       |
|------------|----------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1          | Перейти по URL на страницу авторизации | * Отображается страница авторизации<br/>* Поля Username и Password заполнены сохранёнными значениями Логин и Пароль<br/>* Пароль отображается в маскированном виде<br/>* Кнопка Login активна                             |
| 2          | Перезагрузить страницу                 | Данные формы авторизации заполнены теми же сохранёнными значениями                                                                                                                                                        |
| 3          | Нажать на кнопку Login                 | * Редирект на /inventory.html<br/>* В URL отсутствует параметр /error<br/>* На странице отображается список товаров<br/>* В правом верхнем углу видна иконка Корзина<br/>* В шапке страницы отображается логотип SwagLabs |
