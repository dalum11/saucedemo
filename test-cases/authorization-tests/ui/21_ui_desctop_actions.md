# ID 21 - Проверка функциональности элементов страницы в десктопном разрешении
## Описание
Проверка интерактивности страницы и функциональности элементов в десктопном разрешении браузера
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. В инструментах разработчика установить ширину просмотра 1920px
2. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
3. Страница авторизации загружена
4. Поля ввода пустые, ошибки не отображаются

### Тестовые данные
### Тестовые данные
| Название параметра | Значение                   |
|--------------------|----------------------------|
| Логин              | standard_user              |
| Пароль             | secret_sauce               |

### Шаги
| Номер шага | Название шага                                   | Ожидаемый результат                                                                                  |
|------------|-------------------------------------------------|------------------------------------------------------------------------------------------------------|
| 1          | Навести курсор мыши на поле Username            | * Появляется стандартный курсор ввода (текстовый)<br/>* Кнопка Login неактивна                       |
| 2          | Навести курсор мыши на поле Password            | * Появляется стандартный курсор ввода (текстовый)<br/>* Кнопка Login неактивна                       |
| 3          | Навести курсор мыши на кнопку Login             | * Курсор НЕ меняется на указатель<br/> * Кнопка остаётся неактивной                                  |
| 4          | Кликнуть по полю Username                       | Поле Username получает фокус                                                                         |
| 5          | Нажать клавишу Tab                              | Фокус переходит на поле Password                                                                     |
| 6          | Нажать клавишу Tab ещё раз                      | Фокус переходит на поле Username                                                                     |
| 7          | В поле Username вставить Логин из буфера обмена | * Текст отображается корректно<br/>* Текст не вылезает за поля<br/>* Кнопка Login неактивна          |
| 8          | В поле Password ввести Пароль из буфера обмена  | * Текст отображается корректно<br/>* Текст не вылезает за поля<br/>* Кнопка Login активна            |
| 9          | Нажать на кнопку Login                          | * Редирект на /inventory.html<br/>* Страница каталога корректно отображается в десктопном разрешении |
