# ID 1 - Проверка начального состояния полей ввода
## Описание
Проверка, что поля Username и Password отображаются пустыми с корректными плейсхолдерами при загрузке страницы
### Статус
Успешен
### Приоритет
Критичный
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена

### Тестовые данные
Нет

### Шаги
| Номер шага | Название шага                     | Ожидаемый результат                                                      |
|------------|-----------------------------------|--------------------------------------------------------------------------|
| 1          | Проверить состояние поля Username | * Поле пустое (не предзаполнено)<br/>* Отображается плейсхолдер Username |
| 2          | Проверить состояние поля Password | * Поле пустое (не предзаполнено)<br/>* Отображается плейсхолдер Password |
| 3          | Проверить состояние кнопки Login  | Кнопка неактивна                                                         | 

## Связанный автотест
LoginPageFieldsState.authPage_checkStartFieldsState()
