# ID 14 - Проверка ограничения длины поля Username на фронте
## Описание
Проверка, что поле Username не позволяет ввод более 30 символов
### Статус
Успешен
### Приоритет
Средний
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются
4. Кнопка Login неактивна

### Тестовые данные
Нет

### Шаги
| Номер шага | Название шага                              | Ожидаемый результат                                                          |
|------------|--------------------------------------------|------------------------------------------------------------------------------|
| 1          | В поле Username ввести 29 символов         | * Поле заполнено введённым значением<br/>* Введённый текст не маскируется    |
| 2          | В поле Username ввести 30 символов         | * Поле заполнено введённым значением<br/>* Введённый текст не маскируется    |
| 3          | В поле Username ввести 31 символ           | * Поле заполнено первыми 30 символами<br/>* Последний символ не отображается |                                                                                                                                   |
