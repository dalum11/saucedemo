# ID 26 - Копирование и вставка в Google Chrome
## Описание
Проверка, что в Google Chrome работают копирование и вставка в полях ввода
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Google Chrome открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются
4. Буфер обмена пустой

### Тестовые данные
| Название параметра | Значение      |
|--------------------|---------------|
| Логин              | standard_user |
| Пароль             | secret_sauce  |

### Шаги
| Номер шага | Название шага                                            | Ожидаемый результат                                                                                      |
|------------|----------------------------------------------------------|----------------------------------------------------------------------------------------------------------|
| 1          | В поле Username ввести Логин, выделить, нажать Ctrl + C  | * Поле заполнено<br/>* Введённый текст не маскируется<br/>* Текст выделяется и копируется в буфер обмена |
| 2          | Очистить поле Username и нажать Ctrl + V                 | * Поле заполнено значением Username<br/>* Текст отображается, не маскирован                              |
| 3          | В поле Password ввести Пароль, выделить, нажать Ctrl + C | * Поле заполнено маскированными символами<br/>* Текст выделяется и копируется в буфер обмена             |
| 4          | Очистить поле Password и нажать Ctrl + V                 | * Поле заполнено значением Password<br/>* Текст отображается, маскирован                                 |

## Связанный автотест
