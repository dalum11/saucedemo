# ID 30 - Проверка ввода допустимых символов в поле Password
## Описание
Проверка, что поле Password принимает все допустимые варианты ввода - кириллицы, латиницы, цифр, спецсимволов и пробелов
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля Username и Password пусты  (не предзаполнены)

### Тестовые данные

| Название  параметра | Значение     |
|---------------------|--------------|
| Пароль Латиница     | eng password |
| Пароль Кириллица    | рус пароль   |
| Пароль Цифры        | 1234567890   |
| Пароль Спецсимволы  | !@#$%^&*()_+ |
| Пароль Смешанный    | 123тышosz^&* |

### Шаги
| Номер шага | Название шага                           | Ожидаемый результат                                                                                                     |
|------------|-----------------------------------------|-------------------------------------------------------------------------------------------------------------------------|
| 1          | В поле Password ввести Пароль Латиница  | * Пароль отображается в поле<br/>* Под полем Password нет ошибок<br/>* Ввод не обрезается<br/>* Все символы маскированы |
| 2          | Очистить поле                           | * Поле пустое <br/>* Отображается плейсхолдер Password                                                                  |
| 3          | Повторить шаги 1-2 с Пароль Кириллица   | Результат полностью соответствует этим шагам                                                                            | 
| 4          | Повторить шаги 1-2 с Пароль Цифры       | Результат полностью соответствует этим шагам                                                                            |
| 5          | Повторить шаги 1-2 с Пароль Спецсимволы | Результат полностью соответствует этим шагам                                                                            |
| 6          | Повторить шаги 1-2 с Пароль Смешанный   | Результат полностью соответствует этим шагам                                                                            |

## Связанный автотест
LoginPageFieldsValidation.passwordValidInput_ShouldDisplayCorrectly()
