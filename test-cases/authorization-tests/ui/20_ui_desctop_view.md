# ID 20 - Проверка отображения страницы авторизации в десктопном разрешении
## Описание
Проверка отображения элементов страницы в десктопном разрешении браузера
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. В инструментах разработчика установить ширину просмотра 1920px
2. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
3. Страница авторизации загружена
4. Поля ввода пустые, ошибки не отображаются

### Тестовые данные
Нет

### Шаги
| Номер шага | Название шага                    | Ожидаемый результат                                                                                     |
|------------|----------------------------------|---------------------------------------------------------------------------------------------------------|
| 1          | Проверить общую вёрстку страницы | * Форма авторизации расположена по центру экрана<br/>* Форма имеет фиксированную минимальную ширину     |
| 2          | Проверить шапку Swag Labs        | * Логотип расположен по центру экрана<br/>* Шрифт читаем<br/>* Шапка зафиксирована при скролле          |
| 3          | Проверить поле Username          | * Поле расположено по центру<br/>* Ширина поля составляет 100% доступной ширины (с учётом отступов)     |
| 4          | Проверить поле Password          | * Поле расположено по центру<br/>* Ширина поля составляет 100% доступной ширины (с учётом отступов)     |
| 5          | Проверить кнопку Login           | * Кнопка расположена по центру<br/>* Ширина кнопки составляет 100% доступной ширины (с учётом отступов) |
| 6          | Проверить инфоблок               | * Данные полностью видны<br/>* Скролл не требуется                                                      |
