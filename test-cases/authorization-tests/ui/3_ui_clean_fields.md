# ID 3 - Проверка очистки полей
## Описание
Проверка очистки полей с помощью клавиатуры и кнопки Крестик
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются

### Тестовые данные
| Название параметра | Значение      |
|--------------------|---------------|
| Логин              | standard_user |
| Пароль             | secret_sauce  |

### Шаги
| Номер шага | Название шага                           | Ожидаемый результат                                      |
|------------|-----------------------------------------|----------------------------------------------------------|
| 1          | В поле Username ввести Логин            | * Поле заполнено<br/>* Появляется кнопка Крестик         |
| 2          | Нажать на иконку Крестик                | * Поле полностью очистилось<br/>* Иконка Крестик исчезла |
| 3          | В поле Username ввести Логин            | * Поле заполнено<br/>* Появляется кнопка Крестик         |
| 4          | Нажать Backspace до полной очистки поля | * Поле полностью очистилось<br/>* Иконка Крестик исчезла |
| 5          | Повторить шаги 1-4 для поля Password    | Результат соответствует этим шагам                       |

## Связанный автотест
LoginPageFieldsState.authPage_cleanFields_ShouldCleanCorrectly()
