# ID 18 - Проверка отображения страницы авторизации в мобильном разрешении
## Описание
Проверка отображения элементов страницы в мобильном разрешении браузера
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. В инструментах разработчика установить ширину просмотра 320px
2. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
3. Страница авторизации загружена
4. Поля ввода пустые, ошибки не отображаются

### Тестовые данные
Нет
