# ID 2 - Проверка ввода и маскирования пароля
## Описание
Проверка, что символы в поле Password маскируются по умолчанию, и видимостью элемента можно управлять
через кнопку Глаз
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются

### Тестовые данные
| Название параметра | Значение      |
|--------------------|---------------|
| Пароль             | secret_sauce  |

### Шаги
| Номер шага | Название шага                  | Ожидаемый результат                                                       |
|------------|--------------------------------|---------------------------------------------------------------------------|
| 1          | Ввести в поле Password Пароль  | Символы отображаются в масскированном виде                                |
| 2          | Нажать на иконку Глаз          | * Символы не маскированы<br/>* Кнопка Глаз становится перечёркнутой       |
| 3          | Нажать на иконку Глаз повторно | * Символы снова маскируются<br/>* Кнопка Глаз приобретает изначальный вид |

## Связанный автотест
LoginPageFieldsState.authPage_checkInputAndPasswordMask()
