# ID 29 - Проверка ввода допустимых символов в поле Username
## Описание
Проверка, что поле Username принимает все допустимые варианты ввода - кириллицы, латиницы, цифр, спецсимволов и пробелов
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля Username и Password пусты  (не предзаполнены)

### Тестовые данные

| Название  параметра | Значение     |
|---------------------|--------------|
| Логин Латиница      | eng login    |
| Логин Кириллица     | рус логин    |
| Логин Цифры         | 1234567890   |
| Логин Спецсимволы   | !@#$%^&*()_+ |
| Логин Смешанный     | 123тышosz^&* |

### Шаги
| Номер шага | Название шага                          | Ожидаемый результат                                                                                |
|------------|----------------------------------------|----------------------------------------------------------------------------------------------------|
| 1          | В поле Username ввести Логин Латиница  | * Логин полностью отображается в поле<br/>* Под полем Username нет ошибок<br/>* Ввод не обрезается |
| 2          | Очистить поле                          | * Поле пустое <br/>* Отображается плейсхолдер Username                                             |
| 3          | Повторить шаги 1-2 с Логин Кириллица   | Результат полностью соответствует этим шагам                                                       | 
| 4          | Повторить шаги 1-2 с Логин Цифры       | Результат полностью соответствует этим шагам                                                       |
| 5          | Повторить шаги 1-2 с Логин Спецсимволы | Результат полностью соответствует этим шагам                                                       |
| 6          | Повторить шаги 1-2 с Логин Смешанный   | Результат полностью соответствует этим шагам                                                       |
