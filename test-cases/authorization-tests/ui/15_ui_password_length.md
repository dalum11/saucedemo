# ID 15 - Проверка ограничения длины поля Password на фронте
## Описание
Проверка, что поле Password не позволяет ввод более 30 символов
### Статус
Успешен
### Приоритет
Средний
## Выполнение
### Предусловия
1. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
2. Страница авторизации загружена
3. Поля ввода пустые, ошибки не отображаются
4. Кнопка Login неактивна

### Тестовые данные
Нет

### Шаги
| Номер шага | Название шага                      | Ожидаемый результат                                                          |
|------------|------------------------------------|------------------------------------------------------------------------------|
| 1          | В поле Password ввести 29 символов | * Поле заполнено введённым значением<br/>* Введённый текст не маскируется    |
| 2          | В поле Password ввести 30 символов | * Поле заполнено введённым значением<br/>* Введённый текст не маскируется    |
| 3          | В поле Password ввести 31 символ   | * Поле заполнено первыми 30 символами<br/>* Последний символ не отображается |                                                                                                                                   |
