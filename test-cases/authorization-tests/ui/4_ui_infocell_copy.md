# ID 4 - Проверка работы инфоблока с данными для авторизации
## Описание
Проверка работы ыинфоблока и возможноссти копировать данные
### Статус
Успешен
### Приоритет
Средний
## Выполнение
### Предусловия
1. Страница авторизации загружена
### Тестовые данные
Нет

### Шаги
| Номер шага | Название шага                                | Ожидаемый результат                  |
|------------|----------------------------------------------|--------------------------------------|
| 1          | Нажать на любой логин в инфоблоке            | Ничего не происходит                 |
| 2          | Нажать на пароль                             | Ничего не происходит                 |
| 3          | Выделить любой логин и скопировать его       | Текст скопирован в буфер обмена      |
| 4          | Вставить скопированный текст в поле Username | Текст вставлен и отображается в поле |
| 5          | Повторить шаги 3-4 для поля Password         | Результат соответствует этим шагам   |
