# ID 19 - Проверка функциональности элементов страницы в мобильном разрешении
## Описание
Проверка интерактивности страницы и функциональности элементов в мобильном разрешении браузера
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. В инструментах разработчика установить ширину просмотра 320px
2. Браузер открыт в режиме Инкогнито или очищены cookies и localStorage
3. Страница авторизации загружена
4. Поля ввода пустые, ошибки не отображаются

### Тестовые данные
### Тестовые данные
| Название параметра | Значение                   |
|--------------------|----------------------------|
| Логин              | standard_user              |
| Пароль             | secret_sauce               |

### Шаги
| Номер шага | Название шага                           | Ожидаемый результат                                                                                             |
|------------|-----------------------------------------|-----------------------------------------------------------------------------------------------------------------|
| 1          | Нажать на поле Username и ввести Логин  | * Фокус в поле<br/>* Клавиатура не перекрывает поле<br/>* Текст вводится корректно<br/>* Кнопка Login неактивна |
| 2          | Нажать на поле Password и ввести Пароль | * Фокус в поле<br/>* Клавиатура не перекрывает поле<br/>* Текст вводится корректно<br/>* Кнопка Login активна   |
| 3          | Нажать на кнопку Login                  | * Редирект на /inventory.html<br/>* Страница каталога корректно отображается в мобильном разрешении             |
