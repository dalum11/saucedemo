# ID 37 - Проверка деталей товара
## Описание
Проверка, что детали товара содержат информацию из связанной с ним карточки
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Выполнен сценарий [ID 5](../../authorization-tests/usecase/5_uc_success_auth.md)
2. Ошибки в консоли браузера отсутствуют
3. Корзина пуста
4. Пользователь находится на главном экране

### Тестовые данные
Нет

### Шаги
| Номер шага | Название шага                             | Ожидаемый результат                                                                  |
|------------|-------------------------------------------|--------------------------------------------------------------------------------------|
| 1          | Нажать на название первой карточки товара | * Переход к странице товара<br/>* URL содержит `inventory-item.html?id={id товара}`  |
| 2          | Проверить название товара                 | Название соответствует названию первой карточки                                      |
| 3          | Проверить описание товара                 | Описание соответствует описанию первой карточки                                      |
| 4          | Проверить цену товара                     | * Цена соответствует цене с карточки товара <br> * Цена выводится в формате `$XX.XX` |
| 5          | Проверить кнопку Add to cart              | Кнопка отображается и доступна для нажатия                                           |
| 6          | Проверить изображение                     | Изображение соответствует изображению первой карточки                                |
