# ID 42 - Скролл в мобильной версии сайта
## Описание
Проверка скролла страницы в мобильной версии сайта
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Выполнен сценарий [ID 5](../../authorization-tests/usecase/5_uc_success_auth.md)
2. Ошибки в консоли браузера отсутствуют
3. Корзина пуста
4. Используется мобильная версия сайта или эмуляция мобильного устройства в браузере (разрешение - 320 х 568)
5. Пользователь находится на главном экране
6. Скролл страницы находится в верхней позиции

### Тестовые данные
Нет

### Шаги
| Номер шага | Название шага                                  | Ожидаемый результат                                                                                                                                                |
|------------|------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1          | Проверить начальное отображение карточек       | * Отступы между карточками одинаковые <br/>* Шапка сайта видна и содержит логотип "SwagLabs" <br/>* Подвал сайта не виден <br/>* Карточки расположены в 1 - 2 ряда |
| 2          | Свайпнуть вниз до конца с помощью тачпада/мыши | * Карточки проматываются сверху вниз <br/>* Виден подвал сайта <br/>* Всего загрузилось 6 карточек <br/>* Шапка зафиксирована при скролле                          |
| 3          | Свайпнуть вверх до конца страницы              | * Карточки проматываются снизу вверх <br/>* Подвал сайта не виден <br/>* Шапка зафиксирована при скролле                                                           |
