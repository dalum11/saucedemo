# ID 41 - Скролл в десктопной версии сайта
## Описание
Проверка скролла страницы в десктопной версии сайта
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Выполнен сценарий [ID 5](../../authorization-tests/usecase/5_uc_success_auth.md)
2. Ошибки в консоли браузера отсутствуют
3. Корзина пуста
4. Используется десктопная версия сайта (разрешение - 1920 х 1080)
5. Пользователь находится на главном экране
6. Скролл страницы находится в верхней позиции

### Тестовые данные
Нет

| 2          | Проскроллить вниз до конца с помощью тачпада/мыши  | * Карточки проматываются сверху вниз <br/>* Виден подвал сайта <br/>* Всего загрузилось 6 карточек <br/>* Шапка зафиксирована при скролле |
