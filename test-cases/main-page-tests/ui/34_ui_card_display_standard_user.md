# ID 34 - Проверка отображения карточек на главном экране (стандартный пользователь)
## Описание
Проверка отображения карточек товаров на главном экране при авторизации стандартного пользователя
### Статус
Успешен
### Приоритет
Критический
## Выполнение
### Предусловия
1. Выполнен сценарий [ID 5](../../authorization-tests/usecase/5_uc_success_auth.md)
2. Ошибки в консоли браузера отсутствуют
3. Корзина пуста
4. Пользователь находится на главном экране

### Тестовые данные
Нет

### Шаги
| Номер шага | Название шага                                     | Ожидаемый результат                                                                                    |
|------------|---------------------------------------------------|--------------------------------------------------------------------------------------------------------|
| 1          | Проверить URL страницы                            | URL содержит `/inventory.html`                                                                         |
| 2          | Проверить количество карточек товаров             | * Должно быть 6 карточек<br/>* Каждая карточка имеет отступы между предыдущей и соседней               |
| 3          | Проверить отображение элементов в первой карточке | Карточка содержит: <br/>* Название<br/>* Описание<br/>* Фотография<br/>* Цена<br/>* Кнопка Add to cart |
| 4          | Проверить последнюю карточку товара               | Результат аналогичен п.3                                                                               |
