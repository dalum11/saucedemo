# ID 39 - Добавление товара в корзину со страницы товара
## Описание
Проверка добавления одного товара в корзину со страницы товара
### Статус
Успешен
### Приоритет
Высокий
## Выполнение
### Предусловия
1. Выполнен сценарий [ID 5](../../authorization-tests/usecase/5_uc_success_auth.md)
2. Ошибки в консоли браузера отсутствуют
3. Корзина пуста
4. Пользователь находится на главном экране

### Тестовые данные
Нет

### Шаги
| Номер шага | Название шага                                  | Ожидаемый результат                                                                                                                                    |
|------------|------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1          | Проверить начальное состояние счётчика корзины | Счётчик не отображается                                                                                                                                |
| 2          | Нажать на название товара в первой карточке    | * Переход к странице товара<br/>* URL содержит `inventory-item.html?id={id товара}`                                                                    |
| 3          | Нажать на кнопку Add to card в деталях товара  | * Название кнопки меняется на Remove<br/>* Возле иконки корзины появился счётчик с цифрой 1                                                            |
| 4          | Нажать на иконку корзины                       | * Переход к странице `cart.html` <br/>* Товар отображается в корзине <br/>* Название, описание, цена товара соответствуют карточке добавленного товара |
