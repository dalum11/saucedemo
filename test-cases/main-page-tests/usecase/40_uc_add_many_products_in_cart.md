# ID 40 - Добавление нескольких товаров в корзину с главной страницы
## Описание
Проверка добавления нескольких товаров в корзину, состояния счётчика и корзины
### Статус
Успешен
### Приоритет
Критический
## Выполнение
### Предусловия
1. Выполнен сценарий [ID 5](../../authorization-tests/usecase/5_uc_success_auth.md)
2. Ошибки в консоли браузера отсутствуют
3. Корзина пуста
4. Пользователь находится на главном экране

### Тестовые данные
Нет

### Шаги
| Номер шага | Название шага                                           | Ожидаемый результат                                                                                                                                       |
|------------|---------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1          | Проверить начальное состояние счётчика корзины          | Счётчик не отображается                                                                                                                                   |
| 2          | Нажать на кнопку Add to card на первой карточке товара  | * Название кнопки на карточке меняется на Remove<br/>* Возле иконки корзины появился счётчик с цифрой 1                                                   |
| 3          | Нажать на кнопку Add to card на второй карточке товара  | * Название кнопки на карточке меняется на Remove<br/>* Возле иконки корзины счётчик поменял значение на 2                                                 |
| 4          | Нажать на кнопку Add to card на третьей карточке товара | * Название кнопки на карточке меняется на Remove<br/>* Возле иконки корзины счётчик поменял значение на 3                                                 |
| 5          | Нажать на иконку корзины                                | * Переход к странице `cart.html` <br/>* Товары отображаются в корзине <br/>* Название, описание, цена товаров соответствуют карточкам добавленных товаров |
