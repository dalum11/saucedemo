# ID 35 - Проверка способов открытия карточки товара
## Описание
Проверка, что открыть карточку можно при нажатии на название или фотографию
### Статус
Успешен
### Приоритет
Критический
## Выполнение
### Предусловия
1. Выполнен сценарий [ID 5](../../authorization-tests/usecase/5_uc_success_auth.md)
2. Ошибки в консоли браузера отсутствуют
3. Корзина пуста
4. Пользователь находится на главном экране

### Тестовые данные
Нет

### Шаги
| Номер шага | Название шага                               | Ожидаемый результат                                                                                                                                    |
|------------|---------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1          | Нажать на название первой карточки товара   | * Переход к странице товара<br/>* URL содержит `inventory-item.html?id={id товара}`<br/>* Данные товара совпадают с данными карточки на главном экране |
| 2          | Нажать на кнопку Back to products           | * Переход к главному экрану<br/>* URL содержит `inventory.html`                                                                                        |
| 3          | Нажать на фотографию первой карточки товара | Результат аналогичен п.1                                                                                                                               |
| 4          | Нажать на стрелку Back to products          | Результат аналогичен п.2                                                                                                                               |
