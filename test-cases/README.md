# Ручные тест-кейсы проекта saucedemo
Набор содержит ручные тест-кейсы для функционального тестирования веб.
Тест-кейсы реализуют основные пользовательские сценарии, которые необходимо 
реализовать в виде автотестов на Selenium Java

**Назначение документа**
- Документирование ожидаемого поведения системы
- Возможность ручного прогона, если нет автотестов
- Отображение связей между ручным тестированием и автоматизацией

## Структура тест-кейсов
```text
test-cases/
└── README.md                          # Описание набора тестов
    └── authorization-tests/           # Набор тест-кейсов авторизации
```

## Типы тест-кейсов
### Авторизация - authorization-tests/
**Цель:** Проверить сценарии входа в систему

**Связь с автотестами:** Каждый тест-кейс соответсвует тесту в tests/auth

## Как использовать
### Запуск ручного тестирования
1. Открыть файл с нужным набором тест-кейсов
2. Последовательно выполнить шаги для каждого тест-кейса
3. Отметить статус (Успешен, Провален, Заблокирован, Пропущен)
4. При обнаружении бага - создать задачу в GitHub с описанием и скриншотами

### Формат тест-кейса
Каждый тест-кейс содержит:

| Поле                | Описание                                                      |
|---------------------|---------------------------------------------------------------|
| ID                  | Уникальный идентификатор тест-кейса                           |
| Описание            | Краткое описание тестируемого функционала                     |
| Приоритет           | Очерёдность выполнения тест-кейса                             |
| Название            | Проверка, которая проводится в тест-кейсе                     |
| Предусловия         | Действия, которые нужно выполнить до начала основной проверки |
| Тестовые данные     | Данные, необходимые для выполнения тест-кейса                 |
| Шаги                | Последовательность действий, которые нужно выполнить          |
| Ожидаемый результат | Что должно произойти после выполнения всех шагов              |
| Статус              | Результат прогона                                             |
| Связанный автотест  | Ссылка на автотест, выполняющий шаги тест-кейса               |
