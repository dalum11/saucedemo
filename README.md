## Тесты, которые есть в проекте

### E2E-тесты - находятся в директории `src/test/java/tests`
Все тесты проекта - Е2Е. Моков нет.

Тесты проверяют полный пользовательский путь по готовым 
ручным тест-кейсам. Такой подход позволяет отловить большинство багов

**Скорость:** медленная, требуется запуск браузера

**Инструменты:** Selenium WebDriver, Allure

**Что проверяют:**
- Работу страниц и переходов между ними
- Взаимодействие с элементами страницы (кнопки, поля ввода, стрелки)
- Отображение элементов (список логинов, карточки товаров, пункты меню)
- Состояния (сохранение корзины, поля заказа)
- Интеграция между компонентами
- Пользовательский путь

**Что НЕ проверяют:**
- Корректность работы отдельных элементов (анимация, нажатие)
- Бизнес-логику в изоляции
- Все возможные комбинации ввода
- Обработку ошибок на уровне АПИ

### Вспомогательные классы для тестирования - находятся в директории `src/test/java`
Классы для настройки тестовой среды, инкапсуляции логики и создания
тестовых данных

- `/core` - базовая инфраструктура, инкапсулируют общую логику для страниц, проверок, тестов и отчётов
- `/data` - тестовые данные для переиспользования в тестах
- `/pages` - Page Object, инкапсулируют логику работы со страницами
- `/scenario` - базовые тестовые сценарии для переиспользования
- `/tests` - набор автотестов, каждый тест представляет ручной тест-кейс

## Работа с тестами
### Инициализация тестовых данных
Данные пользователя (логины, пароли) хранятся в классе Data. Данные теста корзины
(товары, цена и т д) не хардкодятся, а извлекаются с сайта. Данные для формы заказа берутся
из констант или генерируются в тесте

### Настройка тестовой среды
- Браузер запускается автоматически через WebDriverManager
- Конфигурация (URL, таймауты) задаются в TestConfig.java
- Все тесты наследуются от BaseTest, куда вынесена общая логика настройки теста

## Быстрый запуск
### Все тесты
```bash
./mvnw test
```

### Только один класс с тестами (пример - LoginTest)

```bash
./mvnw test -Dtest="LoginTest"
```

### С генерацией Allure-отчёта

```bash
./mvnw clean test 
allure serve target/allure-results
```
